# Lab 2: ALU Transcript Generator

A Python and Bash application that validates course assignment grades from a CSV file, calculates weighted category scores and a 5.0-scale GPA, determines final pass/fail academic standing, identifies eligible formative resubmissions, and automates CSV file archiving.

## How to Run

### 1. Python Grade Evaluator
```bash
python3 grade-evaluator.py
```
Enter `grades.csv` when prompted.

### 2. Bash File Organizer
```bash
chmod +x organizer.sh
./organizer.sh
```
